# Cybersecurity Analysis Tool

## Project Overview

This project demonstrates the use of GitHub for version control and Freshworks for issue tracking in a cybersecurity environment.

The project includes a simple log analysis script and a vulnerability assessment feature. Development follows a feature-branch workflow using GitHub, while issues and progress are tracked in Freshworks.

## Features

- Log analysis for detecting suspicious login attempts
- Vulnerability assessment module
- Version control using GitHub
- Issue tracking using Freshworks

## Technologies

- Python 3
- Git
- GitHub
- Freshworks

## Repository Structure

- main – Production-ready code
- development – Ongoing development
- feature/log-analysis – Log analysis feature
- feature/vulnerability-assessment – Vulnerability assessment feature

## Installation

1. Clone the repository.
2. Install Python 3.
3. Run the project using:

```bash
python log_analysis.py
```
